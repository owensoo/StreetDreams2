STREET DREAMS WEBSITE - HOW TO USE THIS FOLDER

Keep the .html files and the "photos" folder together. The pages load
their pictures from the photos folder, so if you move one without the
other, the pictures will not show.

What is inside:
  street-dreams-scrolling.html   The site as one long scrolling page
  street-dreams-tabs.html        The same site split into tabs
  street-dreams-app.html         Tabs on computers, app-style bottom bar on phones
  street-dreams-hub.html         Home page with big buttons for each section
  photos/                        33 photos, each in two sizes:
                                   name-thumb.webp  small, for the grid
                                   name.webp        larger, opens when tapped

To look at it on your computer:
  Unzip the folder, then double-click any of the .html files.

To put it online (GitHub Pages):
  1. Choose ONE layout and rename that file to index.html
  2. Upload index.html AND the whole photos folder to the repository
  3. Turn on GitHub Pages in the repository settings

To add a new photo later:
  Send it to Claude with the street name, or save a small (about 400 px)
  and a larger (about 1000 px) copy into the photos folder.
